# 修图与交付流程

## 1. 建立任务

从外部原图路径创建私有任务，将 `templates/job.example.md` 复制到任务中填写。批量照片逐一记录原图路径与输出目录，不把照片复制到公开目录。记录源文件校验值、编码尺寸、EXIF 方向、导入后的可视宽高、位深和色彩空间；后续比较使用相同的解码方向与色彩基准。任务资料集中在 `workspace/`，共性经验经匿名化后才整理进此文档。

## 2. 诊断与调整图

观察原图的脸部、手部、服装道具、现场光线、混合色温、景深和路人遮挡。明确主体与保留人物；列出 CHANGE 与 LOCK，并记录允许变化的区域及对应蒙版。默认 LOCK 包含原图底层和原生画布；全局调色须记为整幅授权修改。已有清晰修图指令时按范围执行；仅要求诊断时交付诊断，不改图。

## 3. 基础版

在原生画布导入原图并锁定底层，保留其像素内容；所有操作在上方独立图层、蒙版或调整层中完成，不直接改写底层。优先使用 PhotoCraft 的蒙版和调整层进行背景分离、局部曝光、白平衡、轻微皮肤清理与整体调色。默认保留环境与路人，渐进弱化干扰，避免统一模糊导致剪贴感。分步预览，保存可编辑工程。不得缩放、裁切、扩边或重采样原图画布。

建议图层组（按实测支持能力调整）：

```text
00_SOURCE_LOCKED     原始像素底层，锁定并保持不变
10_CLEANUP           局部修复与对应蒙版
20_SUBJECT_LIGHT     人物局部光影与肤色调整
30_BACKGROUND        背景景深、曝光与颜色
40_GRADE             全局影调
50_FX                可选角色素材、遮挡与光效
90_OUTPUT            输出所需调整
```

## 4. 生成式编辑与特效版

按任务需要调用内置图像工具，并先查看本地目标图片。提示词写清输入角色（局部编辑参考、角色参考、效果素材）、允许变化与保护内容。生成带真实 alpha 的效果素材或授权区域的局部补丁；若生成结果带有整幅背景，只提取所需素材并以蒙版合成，不用其整图结果替换照片。将选用结果保存进私有任务，不直接作为已验收成片。

在基础版之上另存 `fx` 版本，将特效放入独立图层组，分别保留素材、变换和蒙版，匹配光线方向、透视、景深、遮挡和环境反光。可以变换效果素材以适配原图，不改变原图底层或画布尺寸。记录特效实际影响范围，包括羽化、模糊、光晕和环境反光。无角色特效需求时只做基础版。生成内容引起身份或服装变化时退回已接受版本，缩小修改范围；同一缺陷三次修复失败后说明限制。

## 5. 质量检查

- 对照原图整体与局部：身份、表情、姿势、手指、妆容、假发及服装纹样无意外变化。
- 图层与蒙版：没有抠图白边、发丝断裂、虚化溢出、重复纹理或背景重影。
- 光影与颜色：肤色自然，光效方向合理，避免塑料皮肤、死黑、过曝和过饱和。
- 工程：另存到任务目录，重新打开，检查原图底层像素未变、关键图层、蒙版和合成结果；关闭所有处理图层后应恢复基准原图。不要假设所有 PSD 特性都被保留。
- 尺寸：输出可视宽高、方向、画幅与导入基准一致，不接受因 AI 素材分辨率较低而缩小整幅画布。
- 像素：合并所有实际影响蒙版后，比较其范围外的解码像素，记录差异像素数量和最大通道差值。比较必须使用相同方向、位深及色彩空间。全局调色时实际影响范围为整幅，仍须验证原图底层完整与尺寸不变。
- 输出：像素保真成片优先使用无损 PNG。实际色彩转换以工具能力为准，不把写标签当作转换；转换或导出造成范围外像素变化时先解决，无法解决须标记验收未通过。需要 JPEG 时作为额外查看版，说明有损重编码不能保证未修改区域逐像素相同。
- 记录位深、色彩转换与导出设置，不承诺文件字节、ICC 或元数据与源文件相同。原图文件仍保持只读。
- 导出避免写入 GPS 等私人元数据；检查实际导出结果，无法验证时记录限制。

## 6. 交付

在每张原图同级创建 `aifix/`，按版本命名，避免覆盖。检查扩展名与实际编码、原生像素尺寸、文件可读性和像素差异记录，并在任务内记录最终路径。基础版与特效版分开交付，附简短修改说明和限制；PSD 等分层工程默认留在私有任务，只有用户另有要求时才另行交付。
